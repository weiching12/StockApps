# 株研評分 V1.2

`shared/entry-score.js` 是唯一的「波段順勢進場」研究模型，版本為 `entry-score-v1.2`。
五個構面的固定權重依序為趨勢 25%、KD 15%、量價 15%、法人 20%、進場位置與風險 25%。
分數表示條件符合程度，不代表上漲機率、預期報酬或買賣指令。

五項原始構面及權重維持不變。基礎分數為原加權總和；核心條件依序檢查趨勢排列與均線方向、K 高於 D 且未連跌兩日、未發生跌幅超過 0.50% 且 RVOL20 至少 2 倍、近五日法人淨額非負、MA20 正乖離不超過 10% 且十日前低點低於現價與 ATR14 有效。每項回傳 PASS、FAIL 或 UNKNOWN 及判斷數據。每項僅在所屬核心條件 PASS 時保留其原加權貢獻；FAIL 的貢獻計為 0。最終分數等於所有通過條件的加權貢獻總和，不另設 60 分上限；必要資料 UNKNOWN 時不給分。`totalScore` 保留為最終分數的相容欄位。市場清單與個股視窗已不再顯示株研評分；V1.2 僅作為進場研究的計算輸入（趨勢與法人分數、價格資料註記）。

模型沿用 `analyzeHistory()` 的 MA20、MA60、KD，以及 `getPriceVolumeSignal()` 的 RVOL20 與量價分類。
ATR14 採 Wilder 平滑：首個值為 14 個 true range 的算術平均，後續以 `(前值 × 13 + 當日 true range) ÷ 14` 遞推；true range 需要前一日收盤價，因此至少 15 個完整交易日 OHLC。
評估一律要求截至所選日期連續 61 個市場交易日行情，缺漏不以前期資料湊數。法人近五日任何一天缺值、近五日成交量合計為零、量價或均線無法計算時，總分為 `null`，不重新分配權重。

現有正式行情是未還原價格。已知公司行動落在 61 日評估區間時不給分；部分日期尚無公司行動查核資料時，評分明細的「疑慮與風險」列出待核對情況。這不是還原後價格模型，也不能把未查核期間視為無公司行動。

市場 Summary API 的每檔股票只回傳評分、模型版本、通過條件數與缺值原因，不含各核心條件的判斷理由與計算數據（約占原本回應的 37%），避免全市場重複傳送完整評分文字；清單不顯示這些內容，個股評分視窗開啟時一律向 Analysis API 取得。個股 Analysis API 按需回傳相同模型的五項分數、原加權貢獻、實際計入貢獻、計算數據與證據。兩者都以所選交易日重新計算，不讀取後續資料。沒有新增 KV 寫入、D1 資料表或行情同步排程。

## 前期評分比較（已停用）

「較前期 ±X.XX」只顯示在已移除的舊版 V1.2 區塊，因此市場 Summary API 不再計算前一交易日的 V1.2 分數，也不再回傳 `entryScoreChange`；每檔每日少算一次 V1.2。
每日 V1.2 研究快照同樣已停止寫入。V1.2 現在只作為進場研究的輸入（構面強度使用其趨勢與法人分數、資料提醒使用其價格資料說明），畫面不再顯示 V1.2 分數。Summary 快取版本已更新。
線上載入摘要會重新驗證 HTTP 快取，離線時仍可使用原有保存資料。
